# User guide

How the interface works, what every status icon means, and what to do when the result is
not what you expected.

## The sidebar, in the order you will need it

| Entry | What it is for |
|---|---|
| **Playlists → Overview** | The dashboard: one row per playlist Spotisub manages |
| **Playlists → Manage** | Every track, with its match status |
| **Playlists → Missing** | The same list, only the tracks that did not match |
| **System → Tasks** | The scheduled jobs and the work currently running |
| **System → Logs** | The application log, live |
| **System → Check Subsonic** | Tests your server address, user and password |
| **Authenticate Spotify** | Only when the Spotify token has to be renewed |
